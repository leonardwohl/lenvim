# lenvim on Nix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nix supplies every external tool this LazyVim config needs, so the
same config runs on the Mac and on the NixOS hosts jenny and babel.

**Architecture:**
- lenvim becomes a flake. It exports `default` and `java` packages, each a
  `wrapNeovimUnstable` nvim with the tools on PATH and `LENVIM_NIX=1` set.
- The Lua config turns Mason off when it sees `LENVIM_NIX` and otherwise
  behaves exactly as before.
- lazy.nvim still downloads plugins.
- nix-darwin installs `java` through a `git+file:` input. nix-homelab installs
  `default` through a `github:` input.

**Tech Stack:** Nix flakes, nixpkgs `wrapNeovimUnstable`, LazyVim / lazy.nvim,
nix-darwin, NixOS.

**Spec:** `docs/superpowers/specs/2026-11-25-nix-tools-design.md`

## Global Constraints

- **Never push to GitHub.** Commit only on local branches: lenvim `nix-tools`,
  nix-darwin `lenvim`, nix-homelab `lenvim`.
- Before any `git reset`/`checkout`/`stash`, run `git status` and
  `git diff` first. Never discard uncommitted changes.
- Systems: `aarch64-darwin` and `x86_64-linux` only.
- The env var contract between Nix and Lua:
  - `LENVIM_NIX=1` (always set by the wrapper)
  - `LENVIM_LOMBOK_JAR`, `LENVIM_JAVA_DEBUG_DIR`, `LENVIM_JAVA_TEST_DIR`
    (`java` variant only)
- Without the wrapper (`LENVIM_NIX` unset), behaviour must be identical to
  before: Mason enabled, same servers.
- Flakes only see git-tracked files. `git add` new files before any
  `nix build`/`nix flake check`.
- Formatting:
  - Lua: `stylua` (repo has `stylua.toml`).
  - New Nix files: `nixfmt`.
  - Edited Nix files in other repos: only format if `nixfmt --check` passed
    before the edit. Otherwise match the surrounding style by hand.
  - Neither tool is on the Mac's PATH. Run them with
    `nix shell --inputs-from ~/.config/nix nixpkgs#stylua nixpkgs#nixfmt -c …`.
- Commit message trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Spec deviations already decided:
  - The helper module is `lua/config/wrapper.lua`.
  - Mason disabling lives in `lua/plugins/mason.lua`. `lua/plugins/nix.lua`
    stays Nix-language support (nixd).
  - LazyVim's jdtls test keymaps (`<leader>tt/tr/tT`) are not recreated under
    the wrapper. neotest-java covers tests.

- [ ] **Step 2: Write the check harness**

`scripts/check-lsp.lua`
```lua
-- Run inside headless nvim by check-lsp.sh. Waits for every LSP client named in
-- $EXPECT (comma-separated) to attach to the current buffer, then exits 0, or 1 on failure.
local want = vim.split(vim.env.EXPECT, ",")
local function names()
  return vim.tbl_map(function(c)
    return c.name
  end, vim.lsp.get_clients({ bufnr = 0 }))
end

local ok = vim.wait(tonumber(vim.env.TIMEOUT or "30000"), function()
  return vim.iter(want):all(function(n)
    return vim.tbl_contains(names(), n)
  end)
end, 200)

if vim.env.LENVIM_NIX == "1" and vim.env.PATH:find("mason/bin", 1, true) then
  io.stderr:write("mason/bin is on PATH under the Nix wrapper\n")
  ok = false
end
if not ok then
  io.stderr:write("attached: " .. table.concat(names(), ",") .. "\n")
end
vim.cmd(ok and "qa!" or "cquit 1")
```

`scripts/check-lsp.sh`
```bash
#!/usr/bin/env bash
# Opens one fixture per language in headless nvim and checks the expected LSP clients attach.
# Usage: scripts/check-lsp.sh <path-to-nvim> [--java]
set -uo pipefail
nvim=$(realpath "$1")
root=$(cd "$(dirname "$0")/.." && pwd)
fx=$root/tests/fixtures
fail=0

check() {
  local file=$1 expect=$2 timeout=${3:-30000}
  if (cd "$(dirname "$fx/$file")" && EXPECT=$expect TIMEOUT=$timeout \
    "$nvim" --headless "$fx/$file" "+luafile $root/scripts/check-lsp.lua"); then
    echo "ok   $file -> $expect"
  else
    echo "FAIL $file -> $expect"
    fail=1
  fi
}

check sample.lua lua_ls
check sample.nix nixd
check main.tf terraformls
check .github/workflows/ci.yml yamlls
check sample.py pyright,ruff
check rust/src/main.rs rust-analyzer
check sample.toml taplo
check sample.json jsonls
check Dockerfile dockerls
check sample.sh bashls
if [[ ${2:-} == --java ]]; then
  check java/src/main/java/App.java jdtls,sonarlint.nvim 120000
fi
exit $fail
```

- [ ] **Step 4: Write the wrapper**

`nix/wrap.nix`
```nix
# nvim with the tools from tools.nix on PATH. The Lua config still comes from ~/.config/nvim.
{ pkgs, java }:
let
  inherit (pkgs) lib;
  tools = import ./tools.nix { inherit pkgs; };
  vscjava = pkgs.vscode-extensions.vscjava;
in
pkgs.wrapNeovimUnstable pkgs.neovim-unwrapped {
  wrapRc = false;
  wrapperArgs = [
    # suffix, so a project's devshell tools (its own JDK, rust-analyzer, ...) win
    "--suffix"
    "PATH"
    ":"
    (lib.makeBinPath (tools.core ++ lib.optionals java tools.java))
    "--set"
    "LENVIM_NIX"
    "1"
  ]
  ++ lib.optionals java [
    "--set"
    "LENVIM_LOMBOK_JAR"
    "${pkgs.lombok}/share/java/lombok.jar"
    "--set"
    "LENVIM_JAVA_DEBUG_DIR"
    "${vscjava.vscode-java-debug}/share/vscode/extensions/vscjava.vscode-java-debug/server"
    "--set"
    "LENVIM_JAVA_TEST_DIR"
    "${vscjava.vscode-java-test}/share/vscode/extensions/vscjava.vscode-java-test/server"
  ];
}
```

### Task 2: Mason off under the wrapper, nixd for Nix

**Files:**

**Interfaces:**
- Consumes: the `LENVIM_NIX=1` env var from Task 1.
- Produces: `require("config.wrapper")`, which returns `{ active: boolean, has: fun(bin: string): boolean }`.
  - `has(bin)` is true without the wrapper.
  - Under the wrapper, `has(bin)` is true only when `bin` is executable.

- [ ] **Step 1: Write the helper**

`lua/config/wrapper.lua`
```lua
-- The Nix wrapper (nix/wrap.nix) sets LENVIM_NIX=1 and puts every tool on PATH.
local M = {}

M.active = vim.env.LENVIM_NIX == "1"

--- Whether a tool's plugin/linter should be configured. Always true without the wrapper:
--- Mason only adds its bin dir to PATH once it loads, after specs are evaluated.
---@param bin string
---@return boolean
function M.has(bin)
  return not M.active or vim.fn.executable(bin) == 1
end

return M
```
